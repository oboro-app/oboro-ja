現在の作業状態の引き継ぎサマリを生成する。

## 手順

まず次の情報を収集する。

1. `git status` と `git log --oneline -5` の結果
2. GitHub Issues の未解決事項(`gh issue list -R oboro-app/oboro-ja`)
3. このセッションで実施した変更とその意図

出力は次の形式でまとめる。

- ## 現在の状態(ブランチ、未コミット変更)
- ## 完了した作業
- ## 残作業・次の着手点(具体的なファイルと手順)
- ## 注意点(ハマりどころ、未検証事項)

残作業・未検証事項は GitHub Issue として起票・更新する。運用の正本はリポジトリルートの `AGENTS.md` を参照すること。
